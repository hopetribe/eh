# r31机制选择：B确认日开盘位于MID下方的弱接受过滤

## 选择范围

本轮只使用训练段2021-08-27～2024-08-26的原v5实际B订单、对应Setup和确认日当日可知行情。固定验证、最近年和完整五年没有参与候选选择；历史已经多轮查看，不作为新的前向样本外。

r26～r30已排除取消B去重、延长确认、Setup过期恢复即买、入场后HIGH/MID失效退出及入场首日双分量拒绝。因而本轮只看买入信号收盘前已经完整可知的确认K线，不使用次日实际OPEN、持仓价格、未来收益或个股例外。

## 参数为零的训练筛查

训练段原v5实际B共25笔，14笔最终盈利、11笔最终亏损。检查的自然边界仅包含确认日OPEN/CLOSE/HIGH/LOW、确认日MID、前收和固定Setup HIGH之间的严格大小关系；没有百分比、ATR、分位数或网格参数。

原子关系中，确认日`OPEN < MID`覆盖4笔、跨AAOI/SNOW/TQQQ三股，四笔原交易全部亏损，均值−14.263%、中位−15.707%。四笔来自三个不同B来源：AAOI与SNOW各一笔`B_CRASH_RECOVER`、SNOW一笔`B_BASE_BULL`、TQQQ一笔`B_STAGE_COMPONENT`，不是单一来源消融。

其含义是：B虽在收盘时完成突破确认，但当日开盘仍在布林中轨之下，整根确认K线需要先从中轨下方穿越到满足确认。它是信号形成期的接受质量，不是r29/r30的成交后退出。

反例和多重筛查必须保留：`OPEN < Setup HIGH`覆盖13笔且7赢，`LOW < Setup HIGH`覆盖19笔且11赢，确认阴线只覆盖同一标的一共3笔且含1个赢家，收于当日区间下半部4笔中有2个赢家。`OPEN < MID`只有4个训练事件，仍可能是偶然聚类；完整资金链可能因跳过订单和后续再入场而恶化。

## 唯一选择

冻结唯一候选`B-confirm-open-mid-filter`：若确认日有限正的OPEN严格低于同日有限正MID，只关闭该日B_SIGNAL；相等不关闭，ICON_JUEFAN完全保留，B/JF碰撞仍可通过JF成交。除此之外不改Setup、S、退出或费用。

这是一次有明确过拟合风险的小样本训练假设。下一步必须按冻结协议完整重跑训练资金链；训练失败即停止。若训练通过，固定验证失败即否决，不得改成来源白名单、排除个股、加入距离阈值或把条件扩展到实际入场日。
