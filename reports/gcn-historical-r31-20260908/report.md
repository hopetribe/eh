# GCN r31：B确认日OPEN/MID过滤训练门槛失败

## 结论

唯一候选`B-confirm-open-mid-filter`在训练期改善了CAGR、MDD、Sharpe、交易胜率和中位交易，但实际买点覆盖从11降到9，违反事前冻结的“可行动买点覆盖不得减少”门槛，因此训练阶段正式否决并保留v5。固定验证、最近年、完整五年、成本和留一窗口均未运行，也不按来源、个股或距离阈值救援。

候选只在原v5完成B确认的当日收盘检查：若当日有限正OPEN严格低于同日有限正MID，则关闭该日B_SIGNAL。相等接受；ICON_JUEFAN、S_SIGNAL、Setup时钟、去重、退出和费用全部保留。B/JF碰撞即使B被过滤，JF仍可在下一实际OPEN成交。

## 训练机制证据

训练原v5实际B共25笔，14赢11亏。`OPEN < MID`覆盖4笔、跨AAOI/SNOW/TQQQ三股及`B_BASE_BULL`、`B_STAGE_COMPONENT`、`B_CRASH_RECOVER`三类来源，四笔原交易全部亏损：AAOI −5.003%、SNOW −20.635%和−14.331%、TQQQ −17.083%。

它不是无反例的普遍规律。筛查了多项自然零参数关系：`OPEN < Setup HIGH`的13笔中仍有7个赢家，`LOW < Setup HIGH`的19笔中仍有11个赢家，确认阴线和收于日内区间下半部也都误伤赢家。最终条件只有4个训练事件，存在明显偶然聚类风险。完整筛查与反例见[机制选择](mechanism-selection.md)。

候选完整重算后恰好删除上述4笔亏损交易，没有新增交易；但过滤后的真实空仓路径使B事件从31降到24，并丢失两个原本被v5覆盖的可行动买点：AAOI 2024-07-02和TQQQ 2023-10-26。收益改善不能覆盖信号覆盖率门槛失败，否则可以通过少发信号机械抬高胜率。

训练决定为`selected: null`，失败项仅`buy_covered`。这比“先看验证再决定是否容忍覆盖下降”更严格，也避免把一个4事件小样本规则包装成准确率升级。

## 停止规则与版本状态

按[冻结协议](protocol.md)，训练任一门槛失败立即停止。因此没有创建验证候选，也不把条件改为`OPEN`低于Setup HIGH、只过滤某一来源、排除AAOI/TQQQ或增加MID距离阈值。

r31固化的是一个“表面绩效改善但覆盖门槛失败”的否决检查点，不是生产版本。线上仍为e966a62/v5；正式配方、前端、默认回测和11份用户行情均未改变。
