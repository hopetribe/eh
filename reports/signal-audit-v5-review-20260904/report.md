# 收藏股票近5年日K信号审计

> 研究用途，不构成投资建议。策略回测按信号日收盘确认、下一交易日开盘成交、单边成本0.1%；事件研究与事后机会均为毛收益，不扣交易成本。

## 数据与验证设计

- 审计窗口：2021-08-27 至 2026-08-27。
- 训练：2021-08-27～2024-08-26；验证：2024-08-27～2025-08-26；已知回看期：2025-08-27～2026-08-27。
- 指标先用完整历史预热，再切片；训练段只从预注册候选选出一个挑战者，验证段只执行一次晋升门槛。最近一年已在既往研究中查看，本轮仅作回看展示，不参与晋升。组合指标按可用标的等权日收益计算。
- 数据统一截止到2026-08-27；输入文件SHA-256记录在data_audit.json。
- 策略选型核心池（完整5年）：TQQQ、MSFT、NFLX、YINN、SNOW、TSLA、MRNA、NVDA、GOOGL、AAOI。
- 信号/漏点诊断池：TQQQ、MSFT、NFLX、YINN、SNOW、TSLA、MRNA、NVDA、TEM、GOOGL、AAOI；部分历史标的 TEM 只作可用期诊断与外部验证，不参与选型。
- 完整历史参考池共同完整截止日：2026-08-27。
- 部分历史标的（不参与共同日历判定）：TEM。
- ⚠ **来源元数据未通过哈希校验：**MSFT、NFLX、YINN、MRNA、TEM、GOOGL。本轮仅确认OHLC结构与冻结文件哈希；不能据此证明上游来源/复权元数据可信。
- 漏点是事后诊断标签，不是可直接交易的未来函数：买点=±5日局部低点且未来20日最大涨幅≥15%；卖点=±5日局部高点且未来20日最大跌幅≥12%；相邻20日仅保留最强转折。
- 干扰买入=未来20日收盘收益<0且最大不利波动≤-8%；干扰卖出=未来20日收盘仍上涨且最大上涨≥10%。

## 本轮结论与优化顺序

1. **保持v5，不创建v6。** 训练首选hard-stop挑战者在验证段CAGR/Sharpe/MDD为 18.63% / 1.22 / 11.74%，未同时超过v5的 27.35% / 1.41 / 11.29%。
2. **B确认仍是首要优化对象。** 11只诊断池的严格完整20日样本中，B确认63次、胜率55.6%、干扰率42.9%；不能仅凭当前数据继续调阈值。
3. **绝反保持即时。** 绝反47次、胜率66.0%、干扰率34.0%，继续延迟缺乏证据。
4. **S卖暂不加确认。** S卖63次、20日下跌命中率54.0%、干扰率39.7%；下一轮应优先研究盈利保护，而不是放宽S卖。
5. **漏点只作诊断。** 可行动买点覆盖24/180（13.3%），卖点覆盖14/78（17.9%）；不得把未来20日定义的漏点直接写成实盘规则。
6. **下一轮验证方案。** 冻结现有v5与本轮候选定义，等待新增时间外数据，再用预注册的盈利保护候选、逐标的留一和成本压力复核；没有新样本前不继续扫参数。

## 当前正式方案

`b-confirm5-ma20+jf|exit=S|trail=20%|hold=none`

- B买只作为 Setup；随后5根K线内首次收盘突破Setup当日最高价且站上MA20，才生成可执行买点。
- 绝反保持即时入场；它本身已含低位、反包和量能确认。
- 退出信号：`S`。
- 从入场后最高收盘回撤20%时收盘确认，下一根K线开盘退出。
- 不设置最长持有期。

该结论仅在当前收藏池、当前成本与本地冻结数据上成立；事后漏点只用于审计，不能直接成为实盘信号。详细逐笔数据见同目录 CSV。
