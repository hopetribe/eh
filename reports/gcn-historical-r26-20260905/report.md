# GCN r26：原v5真正空仓时，哪些买点被漏掉

## 结论与当前方案

本阶段回到原v5真实订单审计，不再只研究失败r24退出制造的空仓。**确实发现漏点，但“取消去重”不能同时改善准确率：全期33次空仓原始B抑制中，8次当天已有正常确认买点；其余25次只有9次后续20根上涨，14次达到干扰定义。** 9个上涨日期集中在三个标的的三段行情，不能当作9个独立可迁移机会。

最值得继续解决的，是原始触发、已有Setup、五根确认过期及后续价格恢复之间的区别。TQQQ 2025年4月底、AAOI 2026年1月底存在明显漏点；但MRNA、AAOI早期和NFLX的同类触发也包含连续下跌。当前仍采用v5，不启用全局重置或延长确认，不宣称本阶段已提高交易准确率。

r26固化的是可复现的诊断版本，r27在其他窗口统计前已冻结“过期时未满足哪个价格条件、后来首次满足时是否仍缺买点”的研究协议，尚未实现新候选。本轮只在本地固化，不改线上546bde1/v5、行情缓存或真实shadow。

## 1. 范围、成交与统计分母

使用r22冻结的原v5订单、CORE10及同一父行情，未调用成交模拟器。训练2021-08-27～2024-08-26；验证2024-08-27～2025-08-26；最近年2025-08-27～2026-08-26；全期2021-08-27～2026-08-26。这些是已反复研究的历史窗口，不是新的前向OOS。

- 窗口初始为空仓；实际卖出OPEN后的同日CLOSE为空仓；下一实际入场OPEN当天CLOSE已持有。期末末CLOSE强平不制造一个可操作空仓日。
- 原始20根计数及Setup沿全前史保留，窗口起点和卖出均不重置。原始B受抑制意味着不建立新Setup，并不等于旧Setup不能正常确认。
- 原始B、确认B、原始JF、可交易JF分别按自己的触发日期统计，不能混合起点比较“胜率”。下一OPEN到第20根CLOSE的毛价格变化只是事件方向标签，非扣费后的实际交易收益。
- 20根完整且不越过窗口末日才进入方向/干扰分母。上涨为正收益；干扰沿用负收益且区间MAE≤−8%。不扫描周期或阈值，未来标签与实际后续成交不进入逐CLOSE观察。
- 同日B/JF保留两旗标，实际入场按B；原始事件与确认事件可以指向同一次后续成交，只有实际可交易类型记作驱动成交，不能重复相加。

## 3. 不能误判成漏点的八个B抑制

以下原始B虽未建立新Setup，旧Setup同日正常确认，下一OPEN均实际买入：

| 标的 | 抑制且确认的日期 |
|---|---|
| MSFT | 2022-01-31 |
| YINN | 2022-11-07、2023-01-03、2023-12-29 |
| SNOW | 2024-06-27 |
| TSLA | 2023-01-17 |
| AAOI | 2024-07-10、2024-08-19 |

它们不是“少了八次买入”。例如TSLA 2023-01-17后20根+53.229%、YINN 2022-11-07后+67.051%，已经被原生确认捕捉；额外放开原始触发会重复归功。相反AAOI 2024-07-10确认后20根−26.524%，正常执行也可能是干扰买点。

## 4. 确实存在的漏点与完整反例

### TQQQ：持仓期间的旧Setup已经过期，退出后连续原始B仍被计数抑制

验证中TQQQ 2025-04-08纯JF买入，4月22日跟踪退出，原净收益−4.443%。4月9日持仓中出现的Setup已于4月16日过期。卖出后没有pending Setup，4月23、24、25、29日及5月1日原始B计数为2～6，均不建立新Setup，也没有原生可交易B/JF。

这些日期后20根毛涨幅依次+39.393%、+31.226%、+22.769%、+34.777%、+19.372%。这是同一段反弹中的五个重叠观察，不是五笔已经成交的盈利交易。原验证窗口此后没有再次入场。

同窗MRNA 2025-01-22、01-23的空仓抑制分别对应−12.161%、−17.717%，均为干扰。验证“抑制后5/7上涨”全部正例来自TQQQ，不能据此全局重置。

### AAOI：新Setup尚在等待，重复原始B受抑制，随后Setup过期

最近年AAOI在2025-12-15按原S卖出此前JF交易，净收益+61.522%；2026-01-28建立新Setup，1月30日重复原始B受抑制，此时旧Setup仍在等待，2月4日才过期。1月30日后20根毛涨幅+144.013%，原窗口下一次实际入场直到2026-07-31的JF。

因此不能只把它解释为“去重没有重置”：当时已有有效等待中的Setup，五根内确认未通过也是关键。+144.013%是原始日期起算的事后价格标签，不是可成交信号收益或新规则回测结果。

同期MRNA 2025-09-30～10-03四个抑制全部下跌（约−1.814%～−11.849%），其中三个为干扰。最近年抑制信号只有1/5上涨，却有+24.547%的平均20根涨幅，说明均值被AAOI单个极端上涨抬高，不能以均值证明准确率优秀。

### 全期无同日买点的抑制只在三段行情中出现正例

25次中9次上涨：YINN 2024-01-23、01-24、02-06三次；上述TQQQ五次；AAOI一次。余16次下跌，其中14次为干扰，包含AAOI 2022年3～5月连续下探、NFLX 2022年2月和MRNA两段下跌。原数据中的重复触发既延误过恢复，也过滤过连续下跌，不能把连续触发本身当作转强证据。

## 5. Setup过期与其他干扰的优化边界

训练41个在空仓时开始的Setup有15个过期，14个完整20根仅3个上涨、10个干扰。上涨为YINN 2022-05-03 +1.897%、TSLA 2023-08-21 +10.926%、NVDA 2023-02-23 +17.096%。NVDA训练753根零交易、唯一原始B建立Setup后3月2日过期，根因是确认未满足，不是去重。

但过期挡住的下跌包括NFLX 2021-12-22 −35.513%、YINN 2022-10-04 −51.937%、AAOI 2022-05-03 −17.029%。另一个YINN过期时早已通过JF入场，不应视作一次空仓漏买。不能只针对三个上涨例子统一延长确认。

JF全期仅一个真正空仓且被抑制的原始触发：YINN 2022-10-26，20根+44.380%；之前r1接受式JF冷却已否决，本轮不据这个旧赢家重新扫描。S卖出条件本阶段没有更改，S后/跟踪退出后仅作为当时已知的空仓来源，不把已有研究窗口的initial状态变成生产禁买条件。

具体后续方案已固定为r27仅诊断：先区分五根内未越过Setup HIGH、未站上当根MID、两者都未满足；再观察过期后首次同时满足时，原v5是否仍空仓、是否已有原生买点。下一Setup开始即终止旧Setup观察；所有未来结果只作分开的事后标签。没有足够证据前不注册延长窗口、价格恢复即买回或个股例外。

## 6. 验证、复现与版本状态

- r26最终15项专项通过（142.89秒），含四窗全部884个真实价格前缀：训练256、验证120、最近年121、全期387。过去状态与已成熟标签逐值一致，未成熟结果为空，未来入场不回填CLOSE观察。
- 79项相邻研究/执行/配方/金样回归通过（54.84秒）。四窗原订单数、逐股持仓根数、原生B/JF/S及terminal边界均与冻结r22一致；测试禁止调用成交模拟器。
- 全24份正式输出可逐字节复现。36份本轮源码、28份输入、36份原算法及92份父行情副本均与对应原件摘要一致，四窗当前算法与环境一致，训练机制和r27协议仍为冻结摘要。
- 非空目录不覆盖；订单缺失/重复/重叠、来源/价格/根数错误明确拒绝；输入、原算法、父行情、原生当前源码、协议及计算中途变化或环境不符在写结果前拒绝。
- 本轮新增r26模块、测试和报告；未改既有引擎、配方、前端、依赖或旧归档。保留11份用户行情缓存，本地阶段提交不等于生产策略晋升。
