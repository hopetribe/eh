# GCN r19：两根连续破底确认——训练改善，但验证无实质改善

结论：`JF-base-low-confirm2`通过全部训练门槛，但固定验证与v5的17笔实际交易完全相同，被`no_material_improvement`否决。训练年化8.724%→9.530%不能替代跨期有效性；本轮不运行连续、完整五年、留一或成本晋升，不替换线上v5。

本阶段固化了两根确认的可选执行能力、同源验证与失败证据，不是已提高准确率的新生产版本。339项研究/核心/影子/Web/API回归通过；本轮只做本地固化，不推送或部署。

## 1. 冻结规则与因果边界

沿用r18的原生三根底部`LLV(LOW,3)`，只对纯绝反实际入场启用；B+绝反碰撞仍按B优先。次OPEN入场锁定前一信号日价格，持仓中新B/绝反不重置，原B/JF/S信号均不变。

唯一差异：持仓期间必须连续两根CLOSE严格低于固定底部，才挂再下一实际OPEN退出。收复或等于底部立即清零；不是累计两次，也不计入场前收盘。实际入场当根可以计第一次，离场与再入场均清零。盘中LOW不参与，跳空不按理想底部价成交。

等待期间原S、hard_stop及20%收盘跟踪仍可退出；同时触发时保留S/hard_stop/已确认底部/其他退出的既有优先级。0.1%单边费用不变。默认一根确认和未启用底部的旧行为保持不变。

核心10股使用同一冻结输入，先截断窗口末日再计算完整前史；各窗口空仓开始、期末强平。训练2021-08-27～2024-08-26，固定验证2024-08-27～2025-08-26。r18只是历史参照，不参与本轮选型或失败补选。

## 4. 固定验证：全部真实交易相同，因此否决

| 指标 | v5与r19共同结果 |
|---|---:|
| 组合年化收益 | 27.350% |
| 最大回撤 | 11.286% |
| Sharpe | 1.414 |
| 交易 / 净盈利 | 17 / 11 |
| 净交易胜率 | 64.71% |
| 最差单笔 | −23.723% |
| 浮盈转亏 | 5笔 |
| 完整入场事件 / 方向胜率 / 干扰率 | 22 / 63.64% / 36.36% |
| 买点覆盖 / 可行动转折 | 4 / 26 |
| 实际退出覆盖 / 可行动转折 | 1 / 13 |

不仅汇总数相同，17笔交易的标的、入场日、退出日、原因、持有期、净收益和峰值均逐值相同，0次entry_floor退出。额外价格/确认审计列不属于绩效差异。

验证保留全部训练门槛，并要求净胜率和Sharpe不低于v5，同时净胜率严格提高或MDD至少降低5%。前述不劣约束都通过，但没有实质改善，因此唯一失败项为`no_material_improvement`。不能因为训练年化提高、验证没有变差就跳过该门槛；不计算后续晋升窗口，也不声称完整五年占优。

## 5. 为什么验证没有作用：初始底部与利润回吐是不同问题

8笔纯绝反中，6笔持仓内从未收盘低于锁定底部；两笔MRNA只在原跟踪退出前最后一根跌破，均没有连续两根条件。因此结果相同不是配置遗漏或确认参数未生效。

| 股票 / 入场日 | 原退出类型 | 净收益 | 最高收盘浮盈 | 持仓内最长连续破底 |
|---|---|---:|---:|---:|
| TQQQ 2025-04-08 | trail | −4.443% | +15.907% | 0 |
| YINN 2025-04-10 | terminal | +75.397% | +77.064% | 0 |
| TSLA 2025-03-13 | trail | −9.628% | +16.125% | 0 |
| MRNA 2024-11-19 | trail | −9.809% | +22.201% | 1，仅原退出前最后一根 |
| MRNA 2025-02-18 | trail | −13.336% | +8.805% | 1，仅原退出前最后一根 |
| NVDA 2025-04-08 | terminal | +74.761% | +76.450% | 0 |
| AAOI 2025-03-13 | trail | +3.754% | +31.756% | 0 |
| AAOI 2025-04-08 | trail | −13.642% | +14.961% | 0 |

7/8笔原退出时，20%跟踪参考价已高于原三根底部；继续收紧/放宽初始底部确认不能直接处理这些已经反弹、随后回吐的路径。验证5笔绝反亏损均曾浮盈，其中4笔最高浮盈不足20%，旧20%启动的盈利保护本来也不会在这4笔中启动。

固定20%跟踪并不等于保本：扣双边0.1%费用，收盘峰值至少要达到入场OPEN的`1/(0.999²×0.8)`，即上涨25.2504%，其跟踪价才覆盖净保本参考价。即使达到，下一OPEN跳空仍可能亏损；价格恒等式不是理想止损成交承诺，也不是原代码错误。

下一r20只冻结结构风险、净保本与峰值路径诊断：量化实际入场跳空、原三根底部风险R、净浮盈后回落及后续赢家反例，先训练机制再披露既定其他窗口。当前未实现或计算，不直接把盈利保护调到10%或半R，不重复旧盈利保护组合搜索。

## 6. 实现、验证与可复现证据

- 8项执行/训练专项覆盖：连续与非连续跌破、收复/等价重置、入场前不计数、持仓新信号不重置、离场清零、真实次OPEN费用、原S/hard_stop/跟踪优先、terminal/mark前缀及非法配置拒绝。
- 50组默认一根/未启用底部结果与冻结r18引擎逐值一致；旧r18在新共用训练入口生成的6份输出与其冻结工件逐字节相同，默认schema不新增字段。
- 4项验证专项覆盖退出类严格改善门槛、同源价格/确认长度传递、真实成交与旧v5验证逐笔一致、manifest绑定、防覆盖，以及在读取验证行情前拒绝缺失/篡改配置和重新哈希后的训练覆盖下降。
- 旧r7仍要求原来的入场改善，六份验证输出逐字节保持；不会为退出类研究放宽旧r7/r9/r12/r13协议。9项新旧验证联合测试通过（17.65秒）。
- 最终339项研究/核心/金样/影子/Web/API联合回归通过（173.92秒）；之前79项相关回归及335项执行侧联合回归也通过。
- 正式训练2行汇总、100行交易、286行事件、562行转折；固定验证2行汇总、34行交易、108行事件、156行转折。训练6份输出/12份源码、验证6份输出/14份源码及训练父链摘要均核验通过。
- 原协议与bfc065e逐字节一致；训练源码在正式验证前后未变化。确认长度2和ENTRY_FLOOR配置同时绑定训练/验证manifest与逐笔表，额外检查器源码亦冻结。
- 8份源码/测试静态编译、差异检查及11份用户行情缓存保护摘要通过；旧r17/r18共12份输出和21份冻结源码摘要保留原样。
- 父输入SHA-256为`42f1d19b3aacb4d738f01cd6362fa0f68b145115b72449c3dd0d14e02f755094`。可信来源5股TQQQ/SNOW/TSLA/NVDA/AAOI，其余核心股只证明冻结字节完整；TEM不在核心样本中。不更改任何原行情缓存、旧研究工件、配方或前端。
