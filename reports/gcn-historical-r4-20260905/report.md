# GCN历史研究r4：时间退出不是回调入场风险的充分解法

## 结论

四个预先固定的候选全部未通过训练门槛，保留正式v5。没有挑选第二名，也没有计算新候选验证段或最近一年的收益。本次固化的是研究否决证据，不是新的生产策略版本。

最重要的发现：hold10的平均持仓占比已接近v5，但最大回撤仍高出3.14个百分点。因此，新增P回调信号的问题不能仅归因于持有过久；下一步应检验入场时的趋势是否真的恢复，而不是继续搜索更多期限或更紧的止损。

## 数据和口径

- 使用既有不可变快照`reports/signal-audit-v5-review-20260904`，父manifest SHA-256为`42f1d19b3aacb4d738f01cd6362fa0f68b145115b72449c3dd0d14e02f755094`。
- 训练窗口2021-08-27～2024-08-26；核心10股为TQQQ/MSFT/NFLX/YINN/SNOW/TSLA/MRNA/NVDA/GOOGL/AAOI。TEM不参加训练选型。
- 输入先截断到训练末日，再计算指标；20日事件结果不得跨过训练末日。信号收盘确认、下一根实际OPEN成交，单边费用0.1%。组合收益是各标的独立策略日收益等权汇总，并非真实资金逐笔相加。
- TQQQ/SNOW/TSLA/NVDA/AAOI的冻结来源元数据与CSV一致；其余5股来源摘要不匹配，虽可复算但不能据此宣称输入全部可信。未刷新或改写任何行情缓存。
- 四个新规则只作用于新增P来源：5%初始止损加10/20/40根上限，或连续两根CLOSE<MID退出。原v5来源不附加规则；同日原v5与P同时触发时，原v5优先。完整定义见[冻结协议](protocol.md)。

冻结门槛要求年化至少为v5的90%（约7.85%），最大回撤不超过v5的110%（约16.49%）。四个候选均不满足回撤门槛；hold20和MID2还不满足年化门槛。hold40仅略高于年化下限，不构成稳健改善。

四个候选与P-stop5的入场信号完全相同：121个完整20日入场事件，方向胜率52.89%，干扰41.32%；v5为54个、50.00%、48.15%。这些是事件毛收益，不是实际持仓的净交易胜率。改变退出规则不能据此声称信号预测准确率进一步提高。

所有规则的最差单笔仍为-34.38%，来自未修改的原v5路径；新增规则只处理新增来源，不能消除所有旧风险。

分母随各规则实际持仓变化：空仓才有可行动买点，持仓才有可行动卖点。覆盖按实际成交对应的信号日计算，包含风险/期限退出；因此卖点覆盖上升不代表原S信号的预测力提高。峰谷是事后诊断标签，不进入交易规则。

全部91次期限退出及48次MID退出均来自新增P来源。相对原v5，hold10和MID2仍会占用三次原v5入场机会：MSFT 2023-04-28、NFLX 2023-03-27、GOOGL 2024-03-15；原v5这三笔净收益分别为35.74%、26.62%、16.37%。原信号列未改不等于原实际交易路径完全保留。

## 同一入场的保护作用与盈利损失

以下严格匹配同一标的、同一入场日，与旧P-stop5比较。期限规则还会腾出仓位并引入新的后续交易，不能把这些单笔差值直接当成组合收益贡献。

| 标的与入场日 | P-stop5退出/净收益 | hold10退出/净收益 | 解释 |
|---|---|---|---|
| NVDA 2023-12-14 | 2024-07-18 / +151.34% | 2023-12-29 / +2.74% | 147根趋势持仓被截断 |
| MSFT 2023-03-15 | 2024-08-26 / +58.73% | 2023-03-29 / +7.09% | 365根持仓提前终止；对照为窗口末强平 |
| GOOGL 2023-04-28 | 2024-08-26 / +54.92% | 2023-05-12 / +8.79% | 334根持仓提前终止；对照为窗口末强平 |
| MRNA 2024-07-17 | 2024-08-02 / -26.10% | 2024-07-31 / -2.30% | 提前离场避开随后大跌 |
| MSFT 2021-10-14 | 2022-02-24 / -9.11% | 2021-10-28 / +8.18% | 减少趋势反转后的利润回吐 |
| NFLX 2021-09-23 | 2022-01-07 / -7.18% | 2021-10-07 / +8.49% | 减少利润回吐 |

- hold10保留旧P-stop5全部84个入场日，改变25笔退出：15笔改善、10笔恶化，并产生29笔额外后续交易。
- hold20改变17笔：9笔改善、8笔恶化；新增28笔。hold40改变12笔：各6笔；新增18笔。
- MID2改变27笔：16笔改善、11笔恶化；新增28笔。它把上述MRNA亏损改善至-0.69%，但把NVDA +151.34%截成-0.05%，也把TQQQ 2023-04-28入场的+47.28%截成-2.08%。频繁失效退出会错失趋势启动后的正常震荡。

## 下一步优化方向

四个候选的最大回撤谷底均在2022-03-07。hold10已把总持仓占比压到27.5%，仍在2021年11～12月新增了TQQQ、NFLX、NVDA等亏损回调交易；缩短期限并未充分排除趋势转弱期的反复入场。

下一轮只研究入场环境：当前P要求MA60上升和价格高于MA200，但不要求短期MID恢复上行或MA200本身上行。可检验这两种趋势约束能否保留真正回调、排除弱反弹。新规则须另行事前冻结，不根据本轮案例逐股加白名单；本轮四个期限规则不再调参。

本结果是已知历史的回溯研究，多轮选型存在累积过拟合风险。即使下一轮训练通过，仍须按冻结验证、跨标的和成本压力门槛检验，不能保证未来最佳表现。
