# GCN历史研究r24：纯绝反净浮盈后的日内/隔夜共同转负

本协议在r23训练机制形成后、r23其他窗口统计披露前冻结。尚未实现或计算本候选，历史截面已被反复研究，不是新的前向OOS；r17～r21的失败结论保持，不通过改门槛挽救旧候选。

## 训练依据与反例

- 原v5训练44笔曾日内压力含20个赢家，37笔正日内贡献后回落含17个赢家，不支持单因子压力/固定等待天数直接卖出。
- 在原训练持仓CLOSE观察上，曾总净浮盈、此刻日内与隔夜累计因子同时<1，共23笔；B 14笔有6个赢家，纯JF 9笔有1个赢家。该分组是原订单事后诊断，不是候选回测、准确率或净收益改善。
- 唯一原纯JF赢家反例：SNOW 2022-05-27入场，2022-06-10双分量转负，当时净亏4.476%，原最终净赚32.276%。必须披露该笔真实候选退出与后续机会集，不能删股或加例外。
- 其他8笔原净亏不保证提前退出会改善：YINN 2021-09-24观察时净亏5.911%已经差于原最终亏损4.459%，次OPEN还会跳空。此前r21已证实提前退出可能增加亏损再入场，必须按新持仓重新模拟。
- AAOI 2023-05-09、TQQQ 2022-06-16及YINN/SNOW/TSLA早期压力赢家未必在整个候选自身持仓中始终不触发，不能因原训练首次压力分组就声称保留全部赢家。
- 选择纯JF而非全部B受训练来源分组影响，存在选择偏差；不在后续窗口再更换来源、调阈值或选择另一个“最佳”组合。

## 唯一挑战者与因果执行

唯一挑战者`JF-joint-pressure`，唯一对照`v5`。不是r21净保本增加一个缓冲条件；不使用1R、LLV底部、百分比止损、确认根数、盈利保留或冷却组合。

1. 原B_SIGNAL、ICON_JUEFAN、S_SIGNAL、去重、20%收盘跟踪及每边0.1%成本不变；原B+JF碰撞按B，只有纯JF实际入场启用新退出，持仓中后来信号不改来源或重置分量。
2. 每笔实际入场重新建立两个价格分量。入场当根CLOSE的日内累计因子为CLOSE/实际entryOPEN，隔夜累计因子为1；不计入前收盘到实际entryOPEN的跳空。
3. 后续仍持仓的每根CLOSE：隔夜累计乘以当日OPEN/前持仓CLOSE，日内累计乘以当日CLOSE/OPEN。两者乘积还原CLOSE/entryOPEN；不使用盘中HIGH/LOW、入场前峰值或未来数据。
4. 若任一已观察持仓CLOSE满足`CLOSE / entryOPEN * 0.999² > 1`，记录该笔曾净浮盈，直至真实离场清零；不要求达到固定R或百分比峰值。此参考包括双边各0.1%费用，不保证未来成交保本。
5. 在已曾净浮盈后，只有当前日内累计因子严格<1且隔夜累计因子严格<1同时成立，才挂下一实际OPEN退出。任一因子等于/高于1不触发；不加epsilon、持续天数、回落次数或可调阈值。不以分量1或参考净保本价成交。
6. 原S/跟踪及现有退出同时触发时保留原原因，新原因仅用于新增退出。实际OPEN离场先执行、清空状态，当日后续CLOSE不计入旧持仓；以后再入场重新计算，原策略未买的新机会必须由候选自身执行。
7. 最小可选扩展已有引擎，不新增平行模拟器。未启用时原v3/v4/v4-exp/v5及旧risk/profit/floor/breakeven配置、返回schema和旧归档逐值不变。terminal按末CLOSE边界强平，mark前缀保留当时持仓和挂单状态，不伪造次OPEN。
